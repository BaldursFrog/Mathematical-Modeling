# Mathematical Modeling

Материалы по курсу **«Математическое моделирование»**.  
В репозитории собраны итоговые PDF-отчеты по лабораторным работам.

## Лабораторные работы

| Работа | Тема | Файл |
| --- | --- | --- |
| ЛР1 | Математическое моделирование спортивных задач: построение моделей траектории мяча для волейбола и футбола, анализ условий успешного броска/удара и влияния начальных параметров. | `ЛР1_ПИН46_Кашпаров.pdf` |
| ЛР3 | Вычисление числа π методами Монте-Карло и Бюффона: статистическая оценка π, исследование сходимости, сравнение точности методов при разном числе испытаний. | `ЛР3_ПИН46_Кашпаров.pdf` |
| ЛР4 | Модель движения вентилятора, подвешенного на пружине: описание колебаний центра масс, траекторий концов лопастей и условий появления замкнутых кривых типа фигур Лиссажу. | `ЛР4_ПИН-46_Кашпаров.pdf` |
| ЛР5 | Модель «хищник-жертва» Лотки-Вольтерры: исследование динамики двух популяций, равновесного состояния, устойчивости и периодических колебаний системы. | `ЛР5_ПИН-46_Кашпаров.pdf` |
| ЛР6 | Модель гонки вооружений Ричардсона: анализ взаимодействия двух противоборствующих стран, устойчивости системы и влияния параметров угрозы, износа и недоверия. | `ЛР6_ПИН-46_Кашпаров.pdf` |
| ЛР7 | Модель экономического роста: исследование динамики трудовых ресурсов, производственной мощности, национального дохода, потребления и накопления; анализ оптимальной нормы накопления. | `ЛР7_ПИН-46_Кашпаров.pdf` |
