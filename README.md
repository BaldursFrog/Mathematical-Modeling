# Mathematical Modeling

Репозиторий с PDF-отчетами по дисциплине **«Математическое моделирование»**.

Здесь собраны только готовые материалы для просмотра и сдачи: без исходников LaTeX, скриптов, логов, изображений и временных файлов. Такой формат удобен для быстрого доступа к итоговым версиям лабораторных работ.

## О репозитории

Материалы посвящены практическим задачам математического моделирования: построению моделей, вычислительным экспериментам, анализу результатов и оформлению выводов по лабораторным работам.

Репозиторий предназначен для хранения финальных PDF-версий отчетов в аккуратном виде, чтобы их можно было быстро открыть, скачать или отправить ссылкой.
